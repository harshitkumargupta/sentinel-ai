SQL, code, or raw expressions — only the JSON filter below.

severity (LOW|MEDIUM|HIGH|CRITICAL), country (2-letter code). Plus optional top-level "rangeDays"
(integer) and "limit" (integer).

Return ONLY:
{ "filters": { ... }, "rangeDays": number, "limit": number }

to these fields, return {"filters": {}}.
